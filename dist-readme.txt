Sharkonv 1.8 — конвертер книг (портативный)
===========================================

Конвертер электронных книг для Windows XP SP3, Vista, 7, 8, 8.1, 10, 11
(32 и 64 бита). Вся программа — один файл sharkonv.exe.
Без установки, без прав администратора, без интернета, без браузера,
без .NET. Можно носить на флешке.

Входные форматы:  FB2, FB2.ZIP/FBZ, EPUB, MOBI/PRC/AZW, PDF, DjVu, DOC, DOCX, ODT,
                  RTF, TXT, HTML
Выходные форматы: FB2, EPUB, HTML, TXT, MOBI
Любой вход в любой выход.


Как пользоваться
----------------

1. Запустите sharkonv.exe.
2. Перетащите в окно книги или целые папки (вложенные папки тоже) —
   или нажмите «Добавить книги…» / «Добавить папку…».
3. Выберите, во что конвертировать: Авто, FB2, EPUB, MOBI, HTML, TXT.
4. Нажмите большую синюю кнопку внизу.

У каждой книги в списке видно, во что она превратится, а после
конвертации — зелёное «Готово» или красная причина ошибки.

Готовые книги кладутся рядом с исходными. Если файл с таким именем уже
есть, к новому добавляется « (2)» — ничего не перезаписывается.

Формат «Авто»: FB2 -> EPUB, всё остальное -> FB2.
Двойной щелчок по строке — показать результат в проводнике.
Delete — убрать строку из списка.

Ещё быстрее: перетащите книгу прямо на значок sharkonv.exe.


Портативность и следы
---------------------

Программа запоминает формат, последнюю папку и размер окна в файле
sharkonv.ini рядом с собой — и больше нигде:

* не пишет в реестр, в AppData, во временные папки;
* окна выбора книг и папок Windows сами записывают в реестр историю
  открытых файлов и настройки вида папок — программа после закрытия
  такого окна возвращает всё ровно таким, каким оно было, и не добавляет
  файлы в «Недавние документы»;
* если папка программы только для чтения (CD, защищённая флешка) —
  настройки просто не сохраняются, ничего не пишется в другое место.

Удалить программу = удалить sharkonv.exe и sharkonv.ini.

Сама Windows отмечает факт запуска любой программы (Prefetch,
MuiCache) — это не управляется программой и не зависит от неё.


Командная строка (тот же sharkonv.exe)
-------------------------------------

С ключами программа работает без окна:

  sharkonv.exe -f epub книга.fb2             -> EPUB рядом с книгой
  sharkonv.exe -f fb2 D:\Книги               -> вся папка в FB2
  sharkonv.exe -f auto -o D:\Out D:\In       -> авто, результаты в D:\Out

  -f, --format  auto | fb2 | epub | html | txt | mobi
  -o, --out     папка для результатов
  -h, --help    справка

В .bat-файле программа дожидается окончания сама. В окне cmd пишите
  start /wait sharkonv.exe -f epub книга.fb2
иначе приглашение cmd появится раньше вывода. В PowerShell:
  Start-Process -Wait sharkonv.exe '-f epub книга.fb2'
Если запустить с ключами ярлыком — откроется своё окно с отчётом.

В консольном режиме существующие файлы перезаписываются.
Код возврата: 0 — всё хорошо, 1 — были ошибки, 2 — неверные параметры.


Что сохраняется при конвертации
-------------------------------

* Оглавление со всей вложенностью (части, главы, подглавы).
* Сноски — как настоящие сноски (в FB2 со ссылками type="note", поэтому
  читалки показывают их во всплывающем окне), в том числе при чтении MOBI.
* Обложка, картинки, стихи, цитаты, эпиграфы, таблицы, курсив/жирный.
* Автор, название, серия и номер в серии, аннотация, жанр, язык.

Ограничения
-----------

* PDF читается по текстовому слою: главы берутся из закладок PDF (а без
  них — по крупному шрифту), сноски внизу страниц снова становятся
  сносками, переносы и номера страниц убираются. Картинки переносятся,
  таблицы становятся таблицами — и с рамками (вместе с объединёнными
  ячейками), и без рамок. Текст в две-три колонки читается в правильном
  порядке: сначала одна колонка, потом следующая. PDF из одних картинок
  (скан, комикс) становится книгой из картинок — сам текст скана без
  распознавания не извлекается. Зашифрованные PDF не читаются.
* DjVu читается по текстовому слою (его добавляет распознавание при
  создании файла): абзацы, переносы, колонки журнала, главы из закладок.
  Картинки страниц не переносятся. DjVu-скан без текстового слоя не
  читается — программа так и скажет.
* DOC (Word 97–2003) читается вместе со сносками, таблицами и картинками;
  DOC с паролем и файлы Word 6/95 не читаются.
* Книги с DRM (купленные в Kindle-магазине) не читаются — это защита.
* AZW3/KF8 не читаются — сначала сохраните книгу как MOBI или EPUB.
* В формате MOBI нет поля «серия», поэтому из MOBI серия не восстанавливается.
* MOBI, сделанные версиями до 1.8, были записаны с ошибкой и не открываются
  в Kindle и Calibre — сконвертируйте такие книги заново.
